# Wheel-Rail-Contact
code for construction, coding, training and evaluation of wheel-rail contact prediction model.

Document Description

1) requirements.txt: Python environment dependency packages for this project

task 1:
1) Wheel-rail contact force prediction task, including training codes for 6 wheel-rail contact force prediction models.
2) Before training each model, download the input and output files and place them in the corresponding model directories.
3) evaluate_model.py: Code for calculating evaluation metrics.

task 2:
1) Wheel-rail contact patch normal stress field prediction task, including training codes for 6 prediction models.
2) Before model training, download the input and output files and place them in the root directory of Task 2.
3) encoder.py: Encoding code for inputs and outputs.
4) evaluate.py: Code for calculating evaluation metrics.

Input and output files download link: https://doi.org/10.5281/zenodo.20388440
